# ワンワールド月報告（出勤簿・立替経費をスマホで記入 → 20日にPDF）

ワンワールド・ジャパン様へ毎月出す「出勤簿」「立替経費精算書」「交通費精算書」を、スマホで少しずつ入れておき、
20日に3枚まとめたPDFを作る。記録は Googleドライブ `PS_総務部\総務部\会計課\ワンワールド月報告` のスプレッドシートに残る。

- 月度は **前の月の21日〜その月の20日**（11月度 = 10/21〜11/20）。今の出勤簿と同じ
- **出勤**：「出勤」「退勤」ボタンで今の時刻（5分単位）が入る。6時間を超えた退勤は休憩1:00を自動で入れる。
  日付を押すと区分（出勤・半休・有給・欠勤・休日）・時刻・休憩・備考を直せる。実働と「1か月20時間」の目安を表示
- **交通費**：日付・目的・区間（出発・到着・交通機関・金額）。「帰り（逆順）を足す」、前に入れた経路をワンタッチで呼び出す「よく使う経路」
- **立替**：日付・内容・支払先・領収書の有無・金額。交通費の合計は1行目に自動で入る（「出張 交通費（電車）清算」）
- **報告**：抜けのチェック（退勤の入れ忘れ、精算書の行数 15行／22行 など）→「PDFを作ってフォルダに保存」
  - PDF名：`YYMMDD_ワンワールド月報告_徳永_2026年11月度.pdf`（YYMMDD は申請日）。同じ月度を作り直すと古いPDFはゴミ箱へ
  - 毎月18〜25日にまだPDFを作っていないと、画面の上に「報告日です」と出る
- 電波がないときはスマホに貯めて、つながったら送る。受付URLを入れる前は「お試し」（スマホの中だけ）

## ファイル
公開先：https://ow-geppo.vercel.app （Vercel。GitHub Pages 版は Chrome に「危険なサイト」と誤って出たため使わない）

- `index.html` 画面（`manifest.json`・`sw.js`・`icon.svg` はホーム画面に置くため）
- `gas/Code.gs` スプレッドシート側の受付とPDF作成
- `gas/月報告ひな形.xlsx` 今の出勤簿（11月）・立替経費精算書・交通費精算書の書式をそのまま使ったひな形（3シート）

## 設定（最初の1回だけ・徳永さんが行う）
1. `gas/月報告ひな形.xlsx` を Googleドライブの `PS_総務部\総務部\会計課\ワンワールド月報告` に入れる
2. ドライブでそのファイルを開き、「ファイル」→「Google スプレッドシートとして保存」。
   できたスプレッドシートの名前を `ワンワールド月報告_記録` にする（xlsx の方は消してよい）
3. 「拡張機能」→「Apps Script」→ 最初の文字を消して `gas/Code.gs` の中身を貼り付けて保存
4. 上の関数の選び欄で `setup` を選んで「実行」→ 許可画面で許可（Drive と外部への接続）。
   スプレッドシートに 出勤データ・交通費データ・立替データ・報告履歴 のシートができる
5. 「デプロイ」→「新しいデプロイ」→ 歯車で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**　／　アクセスできるユーザー：**全員**
6. 表示された `https://script.google.com/macros/s/.../exec` を Claude に渡す
7. スマホの Chrome で https://ow-geppo.vercel.app を開き、「設定」に受付URLを貼って保存する
   （受付URLはページ本体には書かない）
8. Chrome のメニュー →「ホーム画面に追加」

`Code.gs` を直したときは「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」（URLは変わらない）。

## スプレッドシート
- 出勤簿／立替経費精算書／交通費精算書：PDFにするひな形。PDFを作るたびにその月度の内容に書き換わる
- 出勤データ：日付／区分／出勤／退勤／休憩／実働／備考／更新日時（1日1行）
- 交通費データ：ID／旅ID／日付／目的／出発／到着／交通機関／金額／順番（1区間1行、同じ旅IDが1回の移動）
- 立替データ：ID／日付／内容／支払先／領収書／金額
- 報告履歴：月度／作成日時／申請日／出勤日数／実働／立替合計／PDFのリンク

## 注意
- 受付URLを知っている人は記録を読み書きできる。URLは人に渡さない。
- 精算書の行数：交通費は15区間、立替は22行（交通費の1行を含む）まで。超えるとPDFは作れない
